# Security policy

Use the **Report a vulnerability** button on the repository's
[Security page](https://github.com/merginit/unpeeled.cli/security) to report a
security issue privately.

If private vulnerability reporting is unavailable, open a public issue without
including vulnerability details and ask the maintainers for a private reporting
channel.

Do not include secrets, private brand exports, or customer data in public issues.
The CLI reads local exports and uses only the public Brand Peel API by default.
